# Quân Portfolio Prototype

Mở `index.html` bằng Chrome/Edge để xem prototype.

## Cấu trúc
- index.html
- style.css
- script.js
- assets/

## Chỉnh nhanh
- Màu: sửa các biến CSS ở đầu `style.css`
- Nội dung: sửa text trong `index.html`
- Ảnh: thay file trong thư mục `assets/` nhưng giữ nguyên tên file
- Contact: thay email / LinkedIn / Instagram trong footer

Đây là bản prototype web tĩnh, chưa deploy.
